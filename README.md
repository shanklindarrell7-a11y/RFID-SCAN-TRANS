# RFID-SCAN-TRANS
Flipper zero app for rfid sniffing

| Protocol | Frequency | Max Range | Clone | Emulate |
|----------|-----------|-----------|-------|---------|
| EM4100   | 125 kHz   | 5-10 cm   | ✅     | ✅      |
| HID Prox | 125 kHz   | 5-15 cm   | ✅     | ✅      |
| Indala   | 125 kHz   | 5-10 cm   | ⚠️     | ✅      |
| IOProx   | 125 kHz   | 5-10 cm   | ⚠️     | ✅      |
| RAW      | Any       | Varies    | ❌     | ✅      |
