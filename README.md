# RFID-SCAN-TRANS
Flipper Zero app for RFID sniffing

## Controls

### Signal Navigation:
- **LEFT/RIGHT**: Jump 10 signals
- **OK**: Select signal
- **BACK**: Return to main

### Transmit Mode:
- **UP/DOWN**: Adjust power level
- **LEFT/RIGHT**: Adjust repeat count
- **OK**: Start/stop transmission
- **BACK**: Cancel

### Settings Mode:
- **UP/DOWN**: Navigate settings
- **LEFT/RIGHT**: Adjust values
- **OK**: Save/execute
- **BACK**: Save and return
