# RFID-SCAN-TRANS

Flipper Zero app for RFID sniffing, transmission, and signal management.

## Features

- 📡 **Signal Capture**: Capture RFID signals from 125 kHz and 134 kHz devices
- 📚 **Library Management**: Browse, select, and organize captured signals
- 📤 **Signal Transmission**: Transmit saved signals with configurable power and repeat settings
- 📋 **Signal Duplication**: Duplicate and modify RFID signals
- ⚙️ **Customizable Settings**: Configure capture frequency, storage, and naming preferences

## Controls

For detailed information about application controls and navigation, please see the [CONTROLS.md](CONTROLS.md) documentation.

### Quick Reference

- **Main Menu**: Navigate with directional buttons, capture with OK, exit with long BACK
- **Library Mode**: Browse signals with UP/DOWN, jump 10 with LEFT/RIGHT
- **Transmit Mode**: Configure power and repeat, start/stop with OK
- **Settings Mode**: Adjust preferences and manage storage
- **Duplication Mode**: Copy and modify signals

## Installation

1. Copy the application files to your Flipper Zero's `apps` directory
2. Restart your Flipper Zero or refresh the applications list
3. Navigate to the RFID-SCAN-TRANS app and launch it

## Usage

1. Launch the app from the Flipper Zero applications menu
2. Use the **Main Menu** to navigate between different modes
3. Press **OK** to start capturing RFID signals
4. Captured signals are automatically saved to the Library
5. Use **Library Mode** to browse and select signals
6. Use **Transmit Mode** to replay signals
7. Use **Settings Mode** to customize the application
