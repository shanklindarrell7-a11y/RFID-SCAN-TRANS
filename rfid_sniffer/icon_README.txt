# RFID Sniffer Icon

This file would contain a 10x10 1-bit PNG icon for the application.

Since we cannot create binary PNG files in this environment, you will need to create
an icon file named `rfid_sniffer_icon.png` with the following specifications:

- Size: 10x10 pixels
- Format: PNG
- Color depth: 1-bit (black and white)
- Suggested design: RFID wave symbol or antenna icon

To create the icon:
1. Use an image editor (GIMP, Photoshop, or online tools)
2. Create a 10x10 canvas
3. Draw a simple RFID antenna or wave pattern
4. Export as 1-bit PNG
5. Save as `rfid_sniffer_icon.png` in the rfid_sniffer directory

Alternative: Use Flipper's default RFID icon or copy from existing RFID apps in the firmware.
